##### 1.데이터 준비(loadAsset함수)
```Dart
Future<String> loadAsset() async {
    return await rootBundle.loadString('res/api/list.json');
}
```
- `loadAsset`이라는 함수는 프로젝트 폴더 안의 `res/api/list.json` 파일을 찾아 그 안의 텍스트를 통째로 읽어오는 역할을 한다.
- 파일을 읽는 작업은 시간이 걸릴 수 있으므로 `Future<String>`타입을 반환한다. 즉 "미래에 문자열 데이터를 주겠다"는 약속인 셈!

##### 2.화면 구성(build함수)
```Dart
body: FutureBuilder(
    future : loadAsset(),
    builder : (context, snapshot) {
        // ... 
    },
)
```
- `build`함수는 화면 UI를 그린다. 
- `FutureBuilder`는 `future`속성에 지정된 비동기 작업(`loadAsset()`)의 결과를 기다리면서, 상태에 따라 다른 UI를 보여준다. 
- `builder`는 `snapshot`이라는 객체를 받는데, 여기에는 `Future`의 현재 상태 `connectionState`와 데이터 `data`가 들어있다. 

##### 3.`Future` 상태에 따른 UI 변경 (`switch`문)
`FutureBuilder`는 `snapshot.connectionsState`값에 따라 다른 화면을 그린다. 
- `ConnectionState.waiting` 또는 `ConnectionState.active`:
  - `loadAsset()`함수가 아직 실행 중 (데이터를 불러오는 중)이라는 의미 
  - 이때는 `CircularProgressIndicator`를 보여준다. 
- `ConnectionState.done`:
  - `loadAsset()`함수가 성공적으로 완료되었다는 의미
  - `snapshot.data`에 파일에서 읽어온 JSON 문자열이 들어있음
  - `jsonDecode(snapshot.data!)`: 가져온 문자열을 Dart가 이해할 수 있는 `Map`형태로 변환 
  - `ListView.builder`: 이 `Map` 데이터로 스크롤 가능한 리스트를 만듦 
    - `itemCount` : `list['count']` 값만큼 리스트 아이템을 만든다.
    - `itemBuilder` : 각 아이템의 모양을 정의 `Card`안에 `Text`를 넣어 `list['questions'][index]['title']`값을 보여준다. 

```dart
//  ( ( (list['questions'])[value] )['title'] ).toString()
//  └─⑤─┴──④──┴────③────┴────②────┴───①────┘
child: Text(list['questions'][value]['title'].toString()),
```
**이건 어떻게 보아야하나??**
1. `list` 
   - `jsonDecode`를 통해 변환된 전체 데이터 덩어리(Map)
2. `['questions']`
   - `list`데이터 안에서 key가 `questions`인 값을 꺼낸다. 이 값은 여러개의 질문이 담긴 리스트(배열)  
3. `[value]`
   - `quesions`리스트에서 `value`번째 항목을 가리킴. `value`는 `ListView.builder`가 만들어주는 인덱스 번호, 현재 그리고 있는 리스트 아이템의 순서에 해당됨.
   - 여기까지 실행되면 질문 하나에 대한 데이터(Map)가 선택됨.
4. `['title']`
   - 방금 선택된 질문 데이터 안에서 key가 `title`인 값을 꺼냄.
5. `.toString()`
   - 꺼내온 '질문 제목' 값을 확실하게 문자열 타입으로 변환 

```JSON
{
  "questions": [
    { "title": "첫 번째 질문 제목" },  // value가 0일 때 이 값을 가져옴
    { "title": "두 번째 질문 제목" }   // value가 1일 때 이 값을 가져옴
  ]
}
```
- `list`라는 데이터에서 `questions` 리스트를 찾고, 그 리스트의 `value`번째 항목에 있는 `title`의 값을 가져와 화면에 글자로 보여줘라는 의미.

예를 들어 `value`가 0이라면, JSON 데이터의 첫 번째 질문 제목을 가져오게 된다.
