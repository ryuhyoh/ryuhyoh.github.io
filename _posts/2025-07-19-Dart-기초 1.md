## null safety
```dart 
int? couldReturnNullButDoesnt() => -3; // null을 넣을 수 있음

void main() {
    int? couldBeNullButIsnt = 1; // null로 변경할 수 있음
    
    List<int?> listThatCouldHoldNulls = [2, null, 4]; // List의 int에 null 포함 가능 
    List<int>? nullList; //List 자체가 null일 수 있음
    
    int a = couldBeNullButIsnt; // null을 넣으면 오류 
    int b = listThatCouldHoldNulls.first; // int b는 ?가 없으므로 오류 
    int b = listThatCouldHoldNulls.first!; // null이 아님을 직접 표시
    int c = couldReturnNullButDoesnt().abs(); // null일 수도 있으므로 abs()에서 오류
    int c = couldReturnNullButDoesnt()!.abs(); // null이 아님을 직접 표시
}
```

## 비동기 처리 방식
`비동기(asynchronous)`란 언제 끝날지 모르는 작업을 기다리지 않고 다음 작업을 처리하게 하는 것을 의미

`동기(synchronous)`방식으로만 처리하면 어떤 작업을 하는데 시간이 오래 걸릴 경우 사용자는 실행이 멈춘 것으로 생각하고 프로그램을 종료할 수 있음

다트는 `async`, `await` 키워드를 사용해 비동기 처리를 구현한다. 

- 함수 본문 앞에 `async` 키워드를 붙인 다음
- 언제 끝날지 모르는 작업을 `await` 키워드로 지정 
- 이때 값을 여러 개 반환하면 `Future` 클래스
- 값이 연속적이라면 `Stream` 클래스를 활용

```dart
void main(){
    checkVersion();
    print('end process');
}

Future checkVersion() async {
    var version = await lookUpVersion();
    print(version);
}

int lookUpVersion() {
    return 12;
}
```

`checkVersion`함수는 비동기로 진행되기 때문에, 메인함수에서는 이 함수의 리턴을 기다리지 않고 곧바로 `end process`메시지를 출력. 

`checkVersion`함수는 `lookUpVersion`함수를 기다린 후, 그 값을 받으면 그 때 다음 줄 실행. 

따라서 결과 값은 
```bash
end process
12
```

`checkVersion()`함수 안에 `await`가 붙은 함수를 따로(비동기)처리해서 그 결과를 `Future`클래스에 저장해 둘 테니 

먼저 `checkVersion()`함수를 호출한 `main()`함수의 나머지 코드를 모두 실행하라는 의미

## 비동기 함수가 반환하는 값 활용하기 
비동기 함수가 반환하는 값을 처리하려면 `then()`핸들러 함수를 이용

```dart
void main(){
    getVersionName().then((value) => {print(value)});
    print('end process');
}

Future<String> getVersionName() async {
    var versionName = await lookUpVersionName();
    return versionName;
}

String lookUpVersionName(){
    return "Android Q";
}
```

```bash
실행결과
end process 
Android Q 
```

`then()` 이외에 `error()` 핸들러도 사용할 수 있는데   
`error()`핸들러는 함수 실행 과정에서 오류가 발생했을 때 실행하여 예외를 처리 한다.

## Dart & Thread 
다트는 하나의 `스레드(Thread)`로 작동하는 프로그래밍 언어이므로 `await` 키워드를 잘 사용해야 한다.

```dart
void main() {
    printOne();
    printTwo();
    printThree();
}

void printOne() {
    print("One");
}

void printThree() {
    print("Three");
}

void printTwo() async {
    Future.delayed(Duration(seconds: 1), () { // <- await를 지정하지 않은 코드
        print("Future!!");
    })
    print("Two");
}
```
```bash
실행결과 
One
Two
Three
Future!!
```

`Future.delayed()`함수는 지정한 시간 동안 기다리고 나서 진행하라는 뜻이므로 여기서는 1초 후에 진행.

`One` 출력 이후에 `printTwo()`함수에 진입하면 Future를 1초 지연했으므로 `async`로 정의한 비동기 함수의 특징에 따라 `Two`를 먼저 출력한다. 그리고 `Three`를 출력하고 `Future!!`를 마지막으로 출력. 

```dart 
void printTwo() async {
    await Future.delayed(Duration(seconds:2),(){
        print("Future!!");
    });
    print("Two");
}
```
```bash
One
Three
Future!!
Two
```

- 위와 같이 수정을 하게 되면, `await`키워드가 붙은 `Future.delayed()`실행의 결과를 기다리게 되고 `printTwo()`함수를 벗어나 `main()`함수의 나머지 코드를 모두 실행 후 `await`이후 코드를 차례대로 실행한다. 

- 이처럼 `await`키워드를 이용하면 `await`가 속한 함수를 호출한 쪽(예: `main()`)의 프로세스가 끝날 때까지 기다리므로 이를 잘 고려해서 프로그램을 작성해야 한다.

## Dart로 데이터 다루기 

### JSON 데이터 주고받기 
`JSON`을 사용하려면 코드에 `dart:convert` 라이브러리를 포함해야 한다.
```dart 
import 'dart:convert';

void main() {
    var jsonString = '''
    [
        {"score": 40},
        {"score": 80}
    ]
''';

var scores = jsonDecode(jsonString);

print(scores is List);
var firstScore = scores[0];

print(firstScore is Map);
print(firstScore['score'] == 40);

}
```
- 이 코드에서 `jsonString`변수에 저장된 데이터가 `JSON`형태의 문자열이다. 
- 이 데이터를 `dart:convert`라이브러리의 `jsonDecode()`함수에 전달하고 그 결과를 `scores` 변수에 저장 
- `jsonDecode()`함수는 `JSON`형태의 데이터를 `dynamic`형식의 리스트로 변환해서 반환
  - 이때 `dynamic`형식이란 컴파일 시점에서 형식 검사를 하지 않고, 런타임 시점에서 형식 검사를 수행하는 형식
- `scores`변수가 리스트인지는 `true`, `false`로 확인할 수 있다. 
- `score is List` 코드는 `score`변수가 리스트면 `true` 반환
  

- `scores`리스트의 첫 번째 값을 `fristScore`에 저장 
- 이 값은 `key`, `value`가 있는 `Map`형식이다. 
- `firstScore['score'] == 40`코드는 `firstScore` 데이터의 `score`키에 해당하는 값이 `40`인지를 확인 

이처럼 `jsonDecode()`함수를 이용하면 서버에서 가져온 `JSON`데이터를 처리할 수 있다.


<br>

```dart
import 'dart:convert';

var scores = [
    {'score': 40},
    {'score': 80},
    {'score': 100, 'overtime': true, 'special_guest': null},
];

void main() {
    var jsonText = jsonEncode(scores);
    print(jsonText == 
        '[{"score":40},{"score":80},'
            '{"score":100,"overtime":true,'
            '"special_guest":null}]');
}
```

### 스트림 통신하기 
앱을 개발하다보면 데이터를 순서대로 주고받아야 할 때가 있다.   
데이터를 순서대로 주고 받도록 화면을 구성했는데 네트워크나 와이파이에서 연결이 끊기거나 특정 API 호출이 늦어져 순서가 달라지면 앱이 원하는 흐름으로 작동하지 않게 된다.  
  
이처럼 데이터를 주고받는 순서를 보장받고 싶을 때 `스트림(stream)`을 이용한다.  
스트림은 처음에 넣은 데이터가 꺼낼 때도 가장 먼저 나오는 데이터 구조이다.  
즉, 스트림을 이용하면 데이터를 순서대로 주고받는 코드를 작성할 수 있다. 

```dart
import 'dart:async';

// Stream 안의 모든 숫자를 더해서 합계를 반환 
Future<int> sumStream(Stream<int> stream) async {
    var sum = 0;
    // stream에서 데이터가 올 때까지 기다리며 하나씩 처리
    await for (var value in stream){
        print('sumStream : $value'); // 자신이 어떤 숫자를 받았는지
        sum += value; //받은 숫자를 sum에 더함 
    }
    return sum; // 모든 숫자를 더한 후 최종 합계를 반환 
}

// 1부터 to까지의 숫자를 순서대로 생성하는 Stream을 만듦 
Stream<int> countStream(int to) async* {
    for (int i = 1; i <= to; i++) {
        print('countStream : $i'); // 자신이 어떤 숫자를 생성하는지 
        yield i; // 숫자를 하나 생성해서 Stream으로 내보냄
    }
}

main() async {
    var stream = countStream(10);
    var sum = await sumStream(stream);
    print(sum); // 55
}
```
- `countStream()`은 데이터 생산자로 볼 수 있다. 
- `async*`로 선언된 **비동기 제너레이터**함수 
  - `async*` : 이 함수가 단 하나의 값이 아닌 **여러 개의 값을 순차적으로 내보내는 `Stream`객체를 반환**한다는 의미 
  - `yield i` : `return`과 달리 함수를 끝내지 않고, `i`값을 스트림으로 **내보낸다(yield)** 그리고 함수의 실행을 잠시 멈추고 소비자가 다음 데이터를 요청할 때까지 대기하다가, 요청이 오면 멈췄던 부분부터 다시 실행된다. 
- 즉, `countStream(10)`을 호출하면 1부터 10까지의 숫자를 **한 번에 전부 만드는 것이 아니라**, 소비자가 원할 때마다 하나씩 만들어서 보내줄 준비를 하는 것

<br>

- `sumStream()`는 데이터 소비자로 볼 수 있다. 
- 이 함수는 `Stream`을 입력받아 그 안의 모든 값을 더하는 역할을 한다. 
  - `async` : 이 함수는 `await` 키워드를 사용하며, 작업이 완료되면 `Future`객체를 반환한다는 의미 
  - `await for (var value in stream)` : `stream`에서 데이터가 나올 때까지 기다렸다가, 데이터가 하나씩 나올 때마다 루프를 실행 
    - `countStream`에게 "다음 데이터 주세요"라고 요청 
    - `countStream`은 `yield`를 통해 데이터를 하나 보내줌 
    - 받은 데이터를 `value`변수에 담아 루프 내부 코드를 실행 
    - 이 과정을 `countStream`이 모든 데이터를 보낼 때까지 반복 

<br>

**전체 실행 흐름**
1. `main` : `countStream(10)`을 호출해 `Stream`객체를 생성. 이때 `countStream`함수 내부 코드는 아직 실행되지 않음.
2. `main` : 생성된 `Stream`을 `sumStream`에 전달하고 `await`로 결과를 기다림
3. `sumStream` : `await for`루프를 만나 `stream`에게 첫 번째 데이터를 요청 
4. `countStream` : 실행 시작 `i`가 1이 되고, 출력 후 `yield 1;`을 통해 숫자 1을 내보내고 실행을 멈춤 
5. `sumStream` : 숫자 1을 `value`에 받아 출력하고 `sum`에 더함
6. `sumStream` : 루프가 반복되어 `stream`에게 다음 데이터를 요청 
7. `countStream` : 멈췄던 부분부터 다시 실행됨. `i`가 2가되고 출력 후 `yield 2;`를 통해 숫자 2를 내보내고 다시 멈춤 
8. `sumStream` : 숫자 2를 받아 `sum`에 더함 

- 이 과정이 `countStream`이 숫자 10까지 모두 `yield`할 때까지 서로 대화하듯 반복된다. 
- `countStream`의 `for`루프가 끝나면 `Stream`이 닫히고, `sumStream`의 `await for`루프도 종료된다. 마지막으로 `sumStream`은 최종 합계를 리턴하고 `main`함수는 이 값을 받아 출력한다. 

```bash
countStream : 1
sumStream : 1
countStream : 2
sumStream : 2
... (생략) ...
countStream : 10
sumStream : 10
55
```
